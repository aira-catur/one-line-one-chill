# One Line One Chill

One single sentence of horror — under 200 characters, meant to frighten a reader in one breath — written to `entry.txt` by a small deterministic Python program. Entry for the make.fun bounty [One Line One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

Run `python3 main.py` — it writes `entry.txt` to the directory named by `MAKEFUN_OUTPUT_DIR`, or to `/output` when that variable is not set.
